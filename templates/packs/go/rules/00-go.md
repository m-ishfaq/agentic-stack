# Go

## Errors

- Wrap with `fmt.Errorf("doing x: %w", err)`.
- Handle the error or return it. Never `_ = err`.
- Sentinel errors use `errors.Is`. Typed errors use `errors.As`.
- No panic for an expected failure.

## Concurrency

- Pass `context.Context` as the first parameter.
- Every goroutine has an owner and a stop path.
- No unbounded goroutine per request.
- Protect shared state with a mutex or a channel, not both.

## Packages

- Small interfaces at the consumer, not the producer.
- No `init()` that performs I/O.
- Return concrete types, accept interfaces.
- Keep `internal/` for code that must not leave the module.

## Tests

- Table tests with `t.Run`.
- Use `t.Cleanup`, not deferred global state.
- No `time.Sleep` to wait for a result.
- Run through the configured testSafe command when a database is involved.
